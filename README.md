# 틱택토

3×3, 5×5, 7×7 보드에서 즐기는 틱택토 게임입니다. 친구와 두 사람이 겨루거나, 컴퓨터와 1대1로 대결할 수 있습니다.

## 실행 방법

`index.html`을 브라우저(Chrome, Edge 등)로 열면 바로 실행됩니다. 별도 설치는 필요 없습니다.

## 게임 방법

- **보드 크기**: 3×3, 5×5, 7×7 중에서 고릅니다.
- **승리 조건**: 가로, 세로, 대각선 중 한 줄을 먼저 완성하면 이깁니다.

| 보드 크기 | 승리에 필요한 개수 |
|-----------|--------------------|
| 3×3       | 3개                |
| 5×5       | 4개                |
| 7×7       | 5개                |

- **게임 모드**
  - **2인용**: 한 화면에서 두 사람이 번갈아 칸을 누릅니다. X가 먼저 둡니다.
  - **컴퓨터 대전**: 내가 X, 컴퓨터가 O입니다. 3×3에서 컴퓨터는 최적의 수를 두기 때문에 이기기 어렵습니다. 5×5와 7×7에서는 바로 이길 수 있으면 이기고, 상대가 이기기 직전이면 막은 뒤 줄을 만들기 좋은 칸을 고릅니다.
- **점수판**: X, 무승부, O의 승수를 보여 줍니다. 보드 크기나 모드를 바꾸면 점수가 0으로 초기화됩니다.
- **다시 시작**: 현재 보드를 지우고 새 판을 시작합니다.

## 파일 구성

- `index.html`: 게임 전체(화면, 스타일, 게임 로직)가 들어 있는 파일입니다.
- `README.md`: 이 설명 파일입니다.
- `.gitignore`: 깃에 올리지 않을 파일 목록입니다.
